Basic Contour Tree Visualizer

Simple Edge Selection Test

Click on edges (gray pipes) to select them. The selection is now fully integrated into the library.

Controls:

  • Left Click: Select single edge (replaces previous selection)
  • Ctrl + Left Click: Toggle edge in selection (multi-select)
  • Mouse Drag: Rotate view
  • Mouse Wheel: Zoom in/out
  • Clear Selection Button: Appears automatically when edges are selected

Node Types: Blue=Minimum, Cyan=Saddle, Red=Maximum
