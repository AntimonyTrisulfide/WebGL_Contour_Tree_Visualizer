Contour Tree Visualizer - Instructions & Keybinds

WebGL Contour Tree Visualizer

Click the ☰ menu button on the right to access all controls. This visualizer automatically loads the sample contour tree from sample.off file.

Features

  • Auto-Load: Sample tree loads automatically on page start
  • Menu Access: All controls organized in collapsible sections
  • Supported Format: OFF files only
  • Interactive Controls: File loading, rendering settings, view controls

Keyboard Controls

A/D: Pan left/right
W/S: Zoom in/out
T/G: Pan up/down
P: Toggle spacing
M: Toggle menu
R: Reset camera
X: Reset position
Ctrl: Select multiple

Mouse Controls

Use mouse to rotate view, click to select edges, hold ctrl to select multiple edges

About the Project

This Contour Tree Visualizer is a WebGL-based tool for visualizing contour trees from OFF files. It features an intuitive interface with collapsible menus, keyboard shortcuts, and interactive controls for loading files and adjusting rendering settings. The visualizer is designed to provide a seamless experience for exploring complex tree structures in 3D.

I made this project as a part of my 8 week long internship at Visualization and Graphics Lab, Computer Science and Automation Department, IISc Bengaluru under the guidance of Prof. Vijay Natarajan
