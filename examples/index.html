About the Project

This tool is used for visualization of topological data using contour trees. This tool would provide aid in analysing scalar functions, with the selection of individual branches and simplification. This is a precursor to have volumetric rendering such that a volume can be segmented using the help of a contour tree. This is mostly used in cases where topological features matter more than geometry, as this helps understand characteristics like, persistence of features and summarization of large fields.

I made this project as a part of my research internship at Visualization and Graphics Lab, Computer Science and Automation Department, IISc Bengaluru under the guidance of Prof. Vijay Natarajan

Mouse Controls

Use mouse to rotate view, click to select edges, hold ctrl to select multiple edges

Keyboard Controls

A/D: Pan left/right
W/S: Zoom in/out
T/G: Pan up/down
P: Toggle spacing
M: Toggle menu
R: Reset camera
X: Reset position
Ctrl: Select multiple
